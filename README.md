# university-labs

Лабораторні роботи та навчальні проєкти з Natural Language Processing, Deep Learning та Machine Learning — виконані під час навчання в Ivan Franko National University of Lviv.

## Структура репозиторію

- **[ml-labs](../../tree/ml-labs)** — Machine Learning лабораторні
- **[dl-labs](../../tree/dl-labs)** — Deep Learning лабораторні
- **[nlp-labs](../../tree/nlp-labs)** — NLP лабораторні
- **[ml-certificates](../../tree/ml-certificates)** — Сертифікати DataCamp

## Технології

Python, pandas, NumPy, scikit-learn, XGBoost, matplotlib/seaborn, TensorFlow/Keras, NLTK
